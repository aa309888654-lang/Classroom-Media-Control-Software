FEATURES

核心功能

课堂上的高频操作全部收进一个面板，点一下即可，不打断讲课节奏。

🎵

分类音乐曲库

内置暖场、背景音乐、冥想、庆典、颁奖、上下舞台、上课铃声等 9 个场景分类、约 101 首正版授权音乐，点分类卡片即播；支持添加自有音乐（MP3 / WAV / M4A / OGG / FLAC）。

🎚️

音乐精细控制

播放/暂停、上下首、音量、循环模式、静音一应俱全；双通道交叉淡入淡出（默认 2 秒，可调 1~4 秒），切歌不再有「咔」的硬切声。

📊

PPT 一键放映

选定课件后一键在投影屏全屏放映，由本机 PowerPoint / WPS 本体执行，稳定可靠；面板上可遥控翻页，课件库支持长按拖动排序。

🎬

视频一键投放

视频窗口固定到投影屏全屏播放，老师留在教师屏遥控：暂停/播放、快进快退、音量、停止，互不打扰。

📡

无线同屏

同一 WiFi 下，手机 / 平板 / 电脑用浏览器扫码或输网址即可把屏幕投上大屏幕，发送端免安装任何软件或驱动。

⏱️

课堂计时器

倒计时预设 15 / 10 / 5 / 1 分钟或自定义时长，大字计时窗口可单独投到投影屏，限时练习、小组讨论都好用。

🪟

多种面板形态

完整面板、迷你坞（收为小横条、贴边自动隐藏）、LED 单屏直控模式、窗口置顶，适配教室触控一体机与报告厅大屏。

🔗

放映联动

放映 PPT 或播放视频时，音乐自动淡出暂停；退出投屏后音乐从暂停处淡入恢复，也可在设置中关闭联动。

⌨️

系统级全局快捷键

面板最小化、焦点在放映窗口上时按键依然生效；退出软件自动注销全部快捷键，不占其他程序的键位。

SCREENSHOTS

界面一览

深色大按钮设计，为教室触控一体机而生。

GETTING STARTED

运行环境与快捷操作

安装版与便携版功能完全一致，任选其一；首次启动若遇 SmartScreen 提示，点「更多信息 → 仍要运行」即可。

  • 操作系统Windows 10 / 11（64 位）
  • PPT 放映需安装 PowerPoint 或 WPS 演示之一；两者都装时优先调用 PowerPoint
  • 显示器单屏可用全部功能；双屏（教师屏 + 投影屏）体验最佳
  • 无线同屏发送设备与教室电脑处于同一 WiFi 局域网
  • 视频格式推荐 MP4（H.264 + AAC）；MKV / HEVC 建议先转码
  • Ctrl + F6播放 / 暂停
  • Ctrl + F3 / F7上一首 / 下一首
  • Ctrl + F1 / F2放映当前 PPT / 退出投屏
  • Ctrl + F9 / F10音量减 / 加
  • Ctrl + F11 / F12上 / 下一个分类并播放
  • Alt + F7 / F8计时器启停 / 重置
  • ~ / Esc面板全屏 / 退出全屏
